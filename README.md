# Zero University — Reimagining the Architecture of Intellect

An Awwwards-quality interactive single-page website inspired by the creative direction, storytelling experience, and visual aesthetics of [why.zero.university](https://why.zero.university/).

---

## ⚡ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI Library**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) (Persistent scroll-driven camera & geometry keyframing)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (Multiplane parallax, masked text reveals, 3D card tilt)
- **Soundscape**: Web Audio API Procedural Synthesizer (Zero asset dependencies)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🌌 Experience Features

1. **Persistent Scroll-Driven 3D World**:
   - WebGL Three.js background canvas with real-time reactive geometry morphing, particle constellations, and chromatic shifts synchronized with page scroll progress.
2. **Circular Gesture Portal**:
   - Interactive drawing canvas in the Hero where visitors trace a circle with their pointer/touch to warp to the next section.
3. **Multiplane Parallax Storytelling**:
   - 6 Narrative sections with staggered vertical velocities, 3D card tilts, and kinetic typography.
4. **3D Frontier Lab**:
   - Interactive Three.js playground with 5 topological presets (Torus Knot, Geodesic Icosahedron, Mobius Ring, Wave Lattice, Helix Core) and 4 real-time shader styles.
5. **Interactive Interface OS**:
   - Dynamic Cognitive Lattice, Live Global Fellow Telemetry, Socratic Inquiries, and Open Artifact Foundry.
6. **Fellowship Application Drawer**:
   - Integrated modal for submitting Cohort IX proposals with instant verification.
